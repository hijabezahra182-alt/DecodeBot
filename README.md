
# ✦ DecodeBot
### Your Ideas, Decoded.

DecodeBot is a rule-based conversational chatbot developed using Python and Streamlit as part of an Artificial Intelligence internship project at DecodeLabs.

It provides predefined responses to user questions about Artificial Intelligence, Python programming, Machine Learning, and Technology through an interactive chat interface.

## 🚀 Features

- Interactive chatbot interface
- Rule-based question recognition
- Keyword matching and question pattern recognition
- Predefined conversational responses
- Artificial Intelligence explanations
- Python programming concepts
- Machine Learning and Deep Learning topics
- Technology-related information
- Jokes and motivational messages
- Conversation history
- New Chat and Clear Conversation options

## 🛠️ Technologies Used

- Python
- Streamlit
- Regular Expressions (RegEx)
- Rule-Based Logic

## 💻 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/hijabezahra182-alt/DecodeBot.git
```

### 2. Navigate to the Project Directory

```bash
cd DecodeBot
```

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Application

```bash
python -m streamlit run app.py
```

The application will open in your default web browser.

## 🧠 How It Works

DecodeBot uses rule-based programming to identify user questions and provide relevant predefined responses.

Its chatbot engine uses:

- Text normalization
- Keyword matching
- Alternative question patterns
- Conditional statements
- Predefined response databases

Unlike generative AI chatbots, DecodeBot does not require an external AI API or machine learning model.
